# typescript-config

Self-contained TypeScript config presets, published as `@howells/typescript-config`. Documentation and outstanding work live in Linear (howells, HOW): [project documentation](https://linear.app/howells/document/typescript-config-project-documentation-003914c2ab25).

```sh
pnpm typecheck
pnpm lint
pnpm test   # checks every preset
```

Don't overwrite others' uncommitted work.
