# typescript-config

Self-contained TypeScript config presets, published as `@howells/typescript-config`. Issues live in Linear (howells, HOW).

```sh
pnpm typecheck
pnpm lint
pnpm test   # checks every preset
```

Don't overwrite others' uncommitted work.
